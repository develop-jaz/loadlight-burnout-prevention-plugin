STUDY RESET — FOUR THEMES

1. Unzip this archive.
2. Open chrome://extensions in Google Chrome.
3. Turn on Developer mode.
4. Click Load unpacked and select the extracted Study_Reset_V6_Four_Themes folder (the one containing manifest.json).
5. Pin Study Reset from the Extensions menu.
6. Open Preferences to switch between V4 Neon Night, V5 Pixel Retro, Creative Sketch, and Rosewater Sky.

Features: six reset activities (select which to show), guided breathing, tasks with estimated minutes and priority, shortest-task or priority-first suggestions, configurable focus timer, completion celebration, optional background Chrome reminders, encouragement toggle, focus/break duration preferences, and persistent settings.

This is a classroom MVP. Browser notifications may require Chrome/OS permission. The timer remembers its end time when the popup closes, but a completed session is recognized when the popup is next opened; no automatic task completion occurs. The demo.html version provides in-page reminders only while the tab remains open. No behavioral stress detection or buddy system is implemented.
